Clash Verge Rev 使用教程：下载安装、导入机场订阅到开启代理

发布于 2026-10-26 适用：Windows / macOS / Linux

Clash Verge Rev 是目前在电脑上最常用的 Clash 客户端之一，界面是中文，支持 Windows、macOS 和 Linux。它本身不带节点，用法很简单：下载安装 → 导入机场订阅 → 选节点 → 打开系统代理。

下载安装

Clash Verge Rev 在 GitHub 上开源发布，请只从项目的官方 Releases 页面下载，不要用来路不明的打包版本。

按你的系统选择安装包：

系统 选择的文件
Windows（大多数电脑） 文件名带 x64-setup.exe 的安装包
Windows（ARM 处理器） 文件名带 arm64-setup.exe 的安装包
macOS（M 系列芯片） 文件名带 aarch64.dmg 的安装包
macOS（Intel 芯片） 文件名带 x64.dmg 的安装包
Linux 对应发行版的 .deb 或 .rpm

macOS 第一次打开如果提示“无法验证开发者”，到 系统设置 → 隐私与安全性 里点“仍要打开”即可。

导入机场订阅

  1. 登录你的机场后台，找到 一键订阅 或 复制订阅链接，选择 Clash 格式。
  2. 打开 Clash Verge Rev，点左侧的 订阅。
  3. 把订阅链接粘贴到顶部的输入框，点 导入。
  4. 导入成功后会出现一张订阅卡片，点一下这张卡片让它变成选中状态，这一步很多人会忘。

订阅链接相当于你的账号密码，不要发给别人，也不要贴到公开的地方。

选择节点

点左侧的 代理，可以看到机场提供的节点分组。

  • 点分组右侧的闪电图标可以测延迟，数字越小越好。
  • 点击某个节点即可切换。
  • 很多机场会提供“自动选择”分组，会自动选当前延迟最低的节点，新手直接用它就行。

开启代理

点左侧的 设置，打开 系统代理 开关。现在浏览器访问国外网站就会经过代理了。

顶部的代理模式建议保持 规则：国内网站直连，国外网站走代理，既快又省流量。全局 模式会让所有流量都走代理，一般只在排查问题时临时用。

TUN 模式（可选）

有些软件不读取系统代理，比如命令行工具、部分游戏。这时可以用 TUN 模式接管全部流量：

  1. 在 设置 里先安装 服务模式（需要管理员权限）。
  2. 打开 虚拟网卡模式（TUN） 开关。
  3. TUN 模式和系统代理二选一即可，一般不需要同时开。

常见问题排查

导入订阅提示失败：检查链接是否复制完整；如果机场订阅地址在国内被屏蔽，导入会超时，可以换个网络或用机场提供的备用订阅地址。

所有节点延迟都显示超时：先把订阅更新一次（订阅卡片右键 → 更新），再确认套餐和流量没有用完。

网页能打开但速度很慢：换一个地区的节点试试，晚高峰时段香港、日本节点通常更拥挤。

如果机场给的是通用订阅链接，也可以用 v2rayN。还没有机场的话，可以先看看我们的 机场推荐榜单。

还没有机场？可以看 Clash 机场推荐：本站整理的机场都提供 Clash 订阅，并说明了哪些 Clash 客户端支持 VLESS 协议。

常见问题

Clash Verge Rev 是免费的吗？

是的，Clash Verge Rev 是开源免费软件。它只是客户端，本身不提供节点，需要导入机场的订阅链接才能使用。

导入订阅后没有节点怎么办？

先确认订阅链接完整复制、没有多余空格；再检查机场套餐是否到期或流量用完。如果订阅地址被墙无法更新，可以先连上其他网络更新一次订阅。

开了系统代理但某些软件还是连不上？

系统代理只对遵守系统代理设置的软件生效。命令行工具、部分游戏和客户端不读系统代理，这时可以开启 TUN（虚拟网卡）模式。
