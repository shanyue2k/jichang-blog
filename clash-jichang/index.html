"Clash 机场"不是一类特殊的机场，只要提供 Clash 订阅就算。本站整理的 29 家都提供，真正要注意的是另一件事：这 29 家的节点全部是 VLESS 协议，老版 Clash 用不了。先选对客户端，再选机场。

导入订阅前先确认：你的 Clash 是 mihomo（Clash Meta）内核吗？

VLESS 只有 mihomo 内核支持。用 Clash for Windows、ClashX、Clash for Android 这类老客户端，导入后会出现节点缺失、报错或连不上。这是 Clash 用户买了机场却用不了的最常见原因。

机场订阅导入 Clash，三步

  1. 复制订阅链接：登录机场官网，在仪表盘或"我的订阅"里找到"一键订阅"，选 Clash 或"复制订阅地址"。
  2. 导入客户端：打开 Clash Verge Rev 的"订阅"页（安卓是"配置"），粘贴链接，点导入。
  3. 选节点、开代理：在"代理"页选一个节点，打开系统代理（安卓点启动），就可以用了。

每一步的截图和细节设置，见 Clash Verge Rev 教程 和 Clash Meta for Android 教程。

常见问题

Clash 导入机场订阅后没有节点，或者提示错误，怎么办？

最常见的原因是客户端内核太旧。本站整理的机场节点都是 VLESS 协议，原版 Clash 内核（Clash for Windows、ClashX、Clash for Android 用的就是）不支持 VLESS，导入后节点会缺失或报错。换成 Clash Verge Rev、Clash Meta for Android 这类 mihomo 内核的客户端就能解决。

Clash 和 Clash Meta、mihomo 是什么关系？

Clash 是最早的开源内核，原作者 2023 年停止维护。Clash Meta 是社区在它基础上继续开发的分支，后来改名 mihomo，加入了 VLESS 等新协议。现在说"Clash 客户端"，基本都应该选 mihomo 内核的。

有免费的 Clash 机场吗？

本站整理的机场都没有免费试用。网上和 GitHub 上分享的免费 Clash 节点大多不稳定、很快失效，而且来源不明，存在隐私风险。想低成本试用，可以先买最便宜的月付套餐。

Clash 规则模式和全局模式选哪个？

日常选规则模式：国内网站直连，国外网站走代理，速度快也省流量。只有某个网站在规则模式下打不开时，再临时切到全局模式。

iPhone 能用 Clash 订阅吗？

iPhone 上更常用的是 Shadowrocket（小火箭），同样支持机场的订阅链接和 VLESS 协议，需要外区 Apple ID 购买下载。
